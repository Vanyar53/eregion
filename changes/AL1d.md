An operation that only failed still makes no card; the caller exclusions, the other columns and the deduplication by operation are unchanged. The card of an operation whose latest line failed after one succeeded says it took effect. `run-command-by-glorfindel-outside-isolation` keeps every operation, failures included, as before.
- **A latest line that names no caller keeps the caller its operation names** (AL1d, #600 ; `docs/glorfindel.md`). In the same four rules, the row of an operation carries `Caller`, `CallerIpAddress`, `CallerAppId` and `CallerObjectId` from a line of the operation that names them when its latest line does not (`take_anyif`, then `iif(isempty(…))`): Glorfindel's own writes stay set aside, its identity elsewhere stays critical, and a Run Command is read under the caller its lines name.
