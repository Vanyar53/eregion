### Added
- **A sister rule for VM restore points, Azure Backup excluded by its public application id: `restorepoint-by-unexpected-caller`** (AL2, #598 ; `docs/glorfindel.md`, « Les points de restauration » ; `docs/operations.md`, ID1 « Les opérations de test »). Measured on the bench on 05/11 (ID1's hypothesis A2): an on-demand Azure Backup of gondolin — what Glorfindel's `snapshot` action does — goes through restore points (`RESTOREPOINTS/WRITE`, then `RETRIEVESASURIS/ACTION`), never a snapshot nor `BEGINGETACCESS`, so `snapshot-by-unexpected-caller` makes no card at each backup; but `RETRIEVESASURIS` hands out SAS URLs to a restore point's disks, the same exit as a snapshot followed by download access, and no rule read it. Decided by Jonathan on 06/11: a sister rule rather than extending the snapshot rule, which does not change (its sha256 is held by a test). The new rule (`source: azure_activity`, detection only, `plane: control`, T1578.001 and T1530, `high`, `critical` under Glorfindel's identity) reads `RESTOREPOINTS/WRITE`, `RESTOREPOINTS/RETRIEVESASURIS/ACTION` and `RESTOREPOINTS/DISKRESTOREPOINTS/BEGINGETACCESS/ACTION` (the same URL through the public API, disk by disk) — not a collection written alone, which holds nothing; one row per operation, its latest line, failures left out. **Azure Backup is excluded, and it alone, by its public application id** (`262044b1-e2ce-469f-a196-69ab7ada62d3`, the same in every tenant of the public cloud: Microsoft Learn, « Back up and restore Azure VMs with PowerShell »), in `Claims.appid` or as the `Caller`: an operation is its own when one of its lines names it and none names anyone else — its last line may carry neither, and a correlation id is the client's to choose (`x-ms-correlation-request-id`), so a backup's id taken up by someone else hides no one. Its card is decided by the code, no action, like every control-plane card. It does not see a restore or a file recovery from the vault, a storage SAS (`LISTSERVICESAS`), the download itself, nor what Azure Backup does under its own identity. The bench proof is written for Jonathan: a backup makes no card; a restore point of gondolin made by hand, then download access to its disk, make two; the `az` commands are reversible, and a query confirms Azure Backup's caller on the 05/11 lines (hypotheses A9, A10). The test reader `kql_subset` now follows `parse_json(…).member`, `["key"]`, `in~`, `!in~`, `!~`, and `arg_max(…, *)` followed by named aggregations.
