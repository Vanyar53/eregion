### Fixed
- **`make release-draft` counts the version's pull request's gate once it is merged** (CI6c, #541; `docs/operations.md`, « La porte de release »). On the 0.5.5 (05/11), the gate was green on the version's pull request (run 41997986094), on origin/main's very tree, and `release-draft` refused it all the same: a `pull_request` run counted only if its `pull_requests` named a base `main`, and GitHub empties that list once the pull request is merged — `release-draft` always runs after the merge, so only a dispatch on `main` could ever pass.
  - The base is now read by the run's commit's pull requests (`GET repos/{owner}/{repo}/commits/{head_sha}/pulls`, the App's *Pull requests* read), which a merge leaves whole: measured on the 0.5.5, its commit gives #537, merged, base `main`, head `chore/release-0.5.5` of this repository. The pull request taken is the one whose head is the run's branch, of this repository (a fork's of the same name never is); it, any other of that head, and any the run still names, must go into `main` of this repository. One read per commit, and only for the runs on origin/main's tree.
  - The guards hold: the run comes from this repository's `chore/release-…` head, a pull request into another branch is passed over (and said), the tree is compared, nothing passes over the gate. A read that fails, an answer that does not read, or a run's commit that is not 40 hex digits refuses, and says it — never taken for a run that is not the gate, an older one deciding in its place.
  - Tests: `tests/unit/test_release.py` (a merged pull request into `main` counts, its run naming none; an open one too; into another branch, merged or open, refused; a fork's or another branch's pull request on the commit, a base of another repository, a head with a pull request into `main` and another elsewhere, the run and the commit's pulls disagreeing — refused; an empty, unreadable or failed read refused and said; one read per commit; the allow-list: the second `gh api`, a GET of a commit's pull requests and nothing else). Mutants M3770–M3774 (`scripts/mutants/CI6c.py`).
