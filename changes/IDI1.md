### Security
- **An identity of Entra ID is enrolled for the bench by two keys, one per plane, and passes the same guard as a VM** (IDI1, #546; `docs/architecture.md`, « Une identité d'Entra ID » ; `docs/design/modele-de-menace.md`, §5). An identity carries no ARM tag: the application's own Microsoft Graph tags name the bench and the zone (`eregion-target=<bench>`, `eregion-zone=<zone>`) **and** the bench's resource group names the application (`eregion-identities=<object id …>`), the two zones agreeing — either key alone enrolls nothing (any member may register an application and tag it, not write the bench's group). The guard (`eregion_core/inscription.py`, `identity_enrollment`, `check_identity`, `GraphEnrollment`) also refuses: a scope that names no tenant (`EREGION_TENANT_ID`); a reader's token or an application of another tenant (`tid`, `appOwnerOrganizationId`); a multi-tenant application; a principal that is not an application's (a managed identity — Glorfindel's, Orodruin's — is never a target); the reader itself, the operator, the protected identities (`EREGION_PROTECTED_IDENTITIES`: Orodruin, the watches) and an application whose principal owns one of them; every identity when the operator is not named (`EREGION_OPERATOR_OBJECT_ID`) or the protected list holds what is no object id. In `production`, a non-destructive technique only. A read that fails refuses; each URL is built from an object id checked first, a next page outside Graph refused. `python -m eregion_core.inscription identity <object id>`, and `make orodruin-identity ID=<object id>` from Orodruin (the ID checked, never expanded by make).
  - Tests: `tests/unit/test_identity_inscription.py` (a fake Graph and a fake ARM, no network).
- **Orodruin may read applications in Microsoft Graph, and nothing else there: its contract reads its Graph token** (IDI1, #546; `docs/design/orodruin-contract.md`, « IDI1 »). `graph_read_enabled` (off by default, `infra/orodruin`) grants Orodruin's managed identity the Graph app role `Application.Read.All`, on Graph's principal found by its published id; the apply asks for a Privileged Role Administrator. A new guarantee of the contract, `graph`, reads the identity's own Graph token (no Graph call): an app role outside `Application.Read.All`, a directory role (`wids`, but the value of a principal without one — a hypothesis to measure), a user's token → `passive`, as an ARM assignment outside the bench. Three outputs for `orodruin.env`: `tenant_id`, `operator_object_id`, `protected_identities`.
  - Tests: `tests/unit/test_orodruin.py`, `infra/orodruin/tests/graph_read.tftest.hcl` (`terraform test`, mock providers).
