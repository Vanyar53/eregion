### Security
- **An identity of Entra ID is enrolled for the bench by two keys, one per plane, and passes the same guard as a VM** (IDI1, #546; `docs/architecture.md`, « Une identité d'Entra ID » ; `docs/design/modele-de-menace.md`, §5). An identity carries no ARM tag: the application's own Microsoft Graph tags name the bench and the zone (`eregion-target=<bench>`, `eregion-zone=<zone>`) **and** the bench's resource group names the application (`eregion-identities=<object id …>`), the two zones agreeing — either key alone enrolls nothing (any member may register an application and tag it, not write the bench's group). The guard (`eregion_core/inscription.py`, `identity_enrollment`, `check_identity`, `GraphEnrollment`) also refuses: a scope that names no tenant (`EREGION_TENANT_ID`); a reader's token of another tenant (`tid`); a multi-tenant application. **Never a target**, the shared list of `eregion_core/never_target.py` (`NeverTarget`: `covers(object_id)`, `why(identity)` — IR1's executor will read the same): Glorfindel's, Orodruin's and Annatar's identities, the operators, the identities Terraform lists (`EREGION_PROTECTED_IDENTITIES`), Microsoft's and other tenants' applications (`appOwnerOrganizationId`), the principal of a resource (a managed identity, an API that exposes roles or scopes or that others hold roles on), an application whose principal owns one of them; unreadable — no operator named (`EREGION_OPERATOR_OBJECT_ID`), an id written wrong — every identity is refused. **Never a privileged identity** (Jonathan, 05/11: IR1's executor will own what is enrolled, and owning an application is acting as it — `privilege_refusal`): a directory role, active or eligible, at any scope; a membership of a group (a group can carry a role); an object its principal owns (owning a group or a principal with a role is holding it); any application permission — none is admitted until a technique of R2 needs one (`ADMITTED_APP_PERMISSIONS`, empty); what it owns and who holds a role on it must have been read, or it is refused; each refusal said. **Accepted on the bench** (Jonathan, 05/11): the guard reads neither the identity's Azure roles outside the bench's group nor its delegated consents; IDI2 (#556) lifts it before any identity that does not come from Celebrimbor is enrolled. In `production`, a non-destructive technique only. A read that fails refuses; each URL is built from an object id checked first, a next page outside Graph refused. `python -m eregion_core.inscription identity <object id>`, and `make orodruin-identity ID=<object id>` from Orodruin (the ID checked, never expanded by make).
  - Tests: `tests/unit/test_identity_inscription.py` (a fake Graph and a fake ARM, no network).
- **Orodruin may read applications in Microsoft Graph, and nothing else there: its contract reads its Graph token** (IDI1, #546; `docs/design/orodruin-contract.md`, « IDI1 »). `graph_read_enabled` (off by default, `infra/orodruin`) grants Orodruin's managed identity the Graph app roles `Application.Read.All` and `RoleManagement.Read.Directory` (the least to read role assignments, active and eligible), read-only, on Graph's principal found by its published id; the apply asks for a Privileged Role Administrator. A new guarantee of the contract, `graph`, reads the identity's own Graph token (no Graph call): an app role outside those two, a directory role (`wids`, but the value of a principal without one — a hypothesis to measure), a user's token → `passive`, as an ARM assignment outside the bench — once the Graph read is **declared** (`EREGION_TENANT_ID` in `orodruin.env`). Undeclared, as every Orodruin at the release: an app role in the token is passive (`graph_undeclared_right`), but a `wids` outside the hypothesis, or a token that cannot be had, is only said by `orodruin-check`, so no Orodruin falls at the release. The value of `wids` is measured at the first `orodruin-check` after the release; the undeclared case then turns strict. Three outputs for `orodruin.env`: `tenant_id`, `operator_object_id`, `protected_identities`.
  - Tests: `tests/unit/test_orodruin.py`, `infra/orodruin/tests/graph_read.tftest.hcl` (`terraform test`, mock providers).
