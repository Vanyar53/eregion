### Added
- **A test user of Entra ID is enrolled for the bench by two halves, the way a VM is: the bench's restricted administrative unit holds it, and the attribute `Eregion.eregionTarget` / `eregionZone` on the user names the bench and the zone** (IDI1b, #573; `docs/operations.md`, « Les utilisateurs de test du banc (IDI1b) » ; `docs/architecture.md`, « Un utilisateur de test d'Entra ID »). `user_enrollment` and `GraphEnrollment.check_user` (`eregion_core/inscription.py`) refuse a half missing, two halves that disagree (another bench, a zone that is not the unit's), a unit that is not restricted, is dynamic, or is not the pinned one (`EREGION_BENCH_ADMIN_UNIT_ID`, never looked up by its name), a guest, a member of another unit, an identity of `never_target`, a directory role active or eligible, a group, an object owned, an application role; a read that fails refuses. `python -m eregion_core.inscription user <id>` says what may run on a user.
  - Hypothesis 13 settled on the locked provider (`azuread` 3.10.0, its schema): it cannot make an administrative unit restricted, nor define an attribute set, a definition or a user's attribute; it can pose a membership and a directory role at a unit's scope. `infra/terraform/scripts/entra_bench_unit.py` does the rest through Microsoft Graph, under the operator's az login: `make celebrimbor-unit-prepare` (read only without `YES=1`; `UNIT=<id>` reads the pinned unit again, restricted and not dynamic, or refused; without `UNIT`, a unit already of that name is refused, never a second one; a unit not yet readable after its creation is read again, then said, never to delete).
  - `infra/terraform/entra_bench_unit.tf`, off by default (`entra_bench_unit_enabled`), the canonical instance only: the unit read by its pinned id (output `entra_bench_unit_id`), test users with no role, group nor licence (`account_enabled` left to IR1's executor), their attribute posed before their membership, and — for IR1's identity executor (`entra_identity_executor_object_id`) — User Administrator at the unit's scope only, Directory Readers at the tenant, Attribute Assignment Reader at Eregion's set, each role template checked against the tenant's own list at plan time. `make celebrimbor-users-plan` / `celebrimbor-users-up`.
  - Tests: `tests/unit/test_user_inscription.py` (a fake Graph), `tests/unit/test_bench_users.py` (the files, the Make targets, the script against a fake az), `infra/terraform/tests/entra_bench_unit.tftest.hcl` (`terraform test`, mock providers).
