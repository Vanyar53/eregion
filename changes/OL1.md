### Fixed
- **H0 requires only the key of the configured model's provider** (OL1, #525, found by GS1; `infra/glorfindel-host/README.md`, « La clé du fournisseur configuré, seule »). `host_env.py` required `ANTHROPIC_API_KEY` whatever `GLORFINDEL_LLM_MODEL` named — even a local model (`ollama/…`), whose logs never leave the machine. It now requires what the model's provider reads, by its LiteLLM prefix: `anthropic/…` or the default, `ANTHROPIC_API_KEY`; `openai/…`, `OPENAI_API_KEY`; `azure/…`, `AZURE_API_KEY` and `AZURE_API_BASE`; `mistral/…`, `MISTRAL_API_KEY`; `ollama/…` (and `ollama_chat/…`), no key but `GLORFINDEL_LLM_BASE_URL` — in the watch's container, LiteLLM's default address is the container itself; an OpenAI-compatible model served at `GLORFINDEL_LLM_BASE_URL` (self-hosted), nothing. A base URL never waives a cloud provider's own key. An unknown provider, or a model with no prefix, is refused with the list. The message names what is missing, never a value — not even the model's, where a key pasted in the wrong variable would show.
  - **One rule, in the core**: `eregion_core/models.py` (`PROVIDER_ENV`, `model_provider`, `required_env`, `missing_env`), so that `make doctor` (GS1) can read it rather than copy it (D1: the core is the only shared layer).
  - **`host_env.py --check`** (run by `make glorfindel-host-push`) holds an existing `host.env` to the same rule, after its console token: a file whose model lacks its provider's variable is not pushed.
  - **`host.env` now carries `MISTRAL_API_KEY`, `AZURE_API_KEY`, `AZURE_API_BASE` and `AZURE_API_VERSION`** when they are set: `docker-compose.yml` passed them to the watch, but `host_env.py` never copied them — an `azure/…` or `mistral/…` H0 had no key. `host.env.example` lists them, and `GLORFINDEL_LLM_BASE_URL`.
  - **The analysis model** (`EREGION_ANALYSIS_MODEL`, Haiku by default) writes the campaign reports, never a decision: its provider's missing key is said when `host.env` is written, not refused.
  - Tests: `tests/unit/test_glorfindel_host.py` (each provider, with its oracle written there; an unknown provider; `--check`; the analysis model said), `tests/unit/test_models.py`. Mutants M3655–M3659 (`scripts/mutants/OL1.py`).
