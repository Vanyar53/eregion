### Security
- **The detections of the return channel are signed by the watch's key, and the injectors count only those the pinned key signed** (SEC21, #530; `docs/design/watch-key.md`, « Les détections signées » ; `docs/design/modele-de-menace.md`, §5 ; `docs/design/orodruin-contract.md`). Since WC1 (#523) other identities than H0 may write the channel; an unsigned detection could skew the measure of a run.
  - **The watch**: each `detections/<run_id>/<signal_id>.json` carries `key` (its fingerprint, said, never trusted) and `sig`, the Ed25519 signature of `eregion.watch-detection/1` — never the heartbeat's domain — and the canonical JSON of every other field: the run (`exercise_run`), the signal (`signal_id`), what was seen (`event`, `ttp`, `resource_id`, `rule`, `watch_run_id`) and when (`detected_at`). The same key as the heartbeat (SEC19); without it, the detection goes unsigned and the watch says it once.
  - **The injectors** (Annatar's wait): a detection counts for « seen » only when the key pinned in `EREGION_WATCH_KEY` — never one read in the channel — signed it under that domain, for the run read, under its own signal's name (`watch_channel.vouched_detections`, `watch_key.detection_refusal`). Unsigned, another key, a signature made for a heartbeat, a field changed or added, copied from another run or another signal, or no key pinned (SEC19's words and gesture): refused, never counted, and said — in the run's output, in Orodruin's journal (`detection_refused`) and in the run's report (`metrics.detection_refused`, at most 20). A run that saw only refused detections is `unknown`, never `missed` (no `detection_missed`, no rule proposed). The heartbeat is unchanged; the local channel of verdicts (SEC18) too.
  - **The passage**: no option admits an unsigned detection. A watch up to date with injectors from before: the two fields are ignored, nothing breaks. A watch from before with injectors up to date: every detection refused (« unsigned … update Glorfindel »), runs `unknown`. The order: the release published, H0's CD deploys it, then Orodruin (OI3 or `make orodruin-push REF=<tag>`), then a workstation's watch (`make glorfindel-restart`). No new key, no new pin.
  - Tests: `tests/unit/test_signed_detections.py` (on the fake container: a signed detection believed, each refusal, the heartbeat unchanged, no key pinned, the console, the journal and the report), `test_watch_channel.py`, `test_annatar_detection.py`, `test_annatar_atomic.py` (their channels now signed). Mutants M3700–M3719 (`scripts/mutants/SEC21.py`).
