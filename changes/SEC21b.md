### Security
- **The watch's signed heartbeat says which detections it covers: a detection removed from the return channel no longer makes a false « missed »** (SEC21b, #535; `docs/design/watch-key.md`, « Ce que le battement couvre »). Left open by SEC21: a hand that can write `watch` could remove a detection under a true heartbeat, and the run concluded « missed » instead of « detected ».
  - **The watch**: the channel's heartbeat carries `covers` — for each window it names in `windows`, the sorted `signal_id` of every detection delivered for it (written and acknowledged before the heartbeat; an empty list for a window with none), signed with the rest under the same domain (`eregion.watch-beat/1`, unchanged: the injectors' gate of before still believes it). At most 256 per window (`MAX_COVERED`): beyond, the window is left out of `covers` and its run cannot conclude to a miss. The local channel of verdicts (SEC18) is unchanged: its heartbeat keeps exactly its fields.
  - **The injectors** (Annatar's wait): at the end of the wait, on the storage channel, the heartbeat is read first, then the detections; a silence is a miss only once every detection the heartbeat covers for the run is read back, vouched (`watch_channel.uncovered`). A detection read that it does not list (delivered after it) is admitted. A covered detection absent is `unknown`, never `missed` (no `detection_missed`, no rule proposed), said in the run's output, in Orodruin's journal (`detection_missing`) and in the run's report (`metrics.detection_missing`, `metrics.detection_missing_total`), the first 20 only (`MAX_MISSING`), the rest counted. A detection of the run read back and vouched is still « detected ».
  - **The passage, strict**: a heartbeat without `covers` (a watch older than this lot) proves no miss — `unknown`, the reason and the gesture said (update Glorfindel: H0 by its CD, a workstation's by `make glorfindel-restart`); a « detected » is untouched. Bounded by the watch's update: H0 first, by its CD, then Orodruin. No new key, no new pin.
  - Tests: `tests/unit/test_beat_covers.py`; mutants M3740–M3749 (`scripts/mutants/SEC21b.py`).
